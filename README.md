# Coworking Reservation API (Backend Laravel)

API RESTful desarrollada en Laravel para la gestión de reservas de espacios de coworking, con autenticación mediante Laravel Sanctum, control de roles y permisos (Spatie Laravel-Permission) y respuestas JSON estandarizadas.

## Requisitos
- PHP >= 8.2
- Composer
- MySQL o SQLite

## Instalación y Configuración

1. Clonar el repositorio e ingresar a la carpeta:
